🛡️ What is SeedSigner?

  • Air-Gapped Hardware: Never connects to the internet
  • DIY Security Device: Built from common Raspberry Pi components
  • Stateless Design: No permanent storage of private keys
  • QR Code Communication: Secure, visual transaction signing
  • Open Source: Fully auditable code and hardware
  • Multi-Signature Support: Can participate in complex setups

A completely offline signing device that puts YOU in control

  • True Self-Custody: Your keys never leave your control
  • Maximum Security: Air-gapped from all networks
  • Cost Effective: ~$50-125 vs $100-300+ commercial devices
  • Transparency: Build it yourself, audit the code

⚙️ How SeedSigner Works

  1. Generate/Import Seed: Create or restore your seed phrase
  2. Air-Gapped Operation: Device never touches internet
  3. Transaction Creation: Use watch-only wallet on networked device
  4. QR Code Transfer: Scan unsigned transaction via camera
  5. Sign Offline: SeedSigner signs with your private key
  6. Broadcast Transaction: Scan signed QR back to networked wallet

🔧 What You Need

Required Hardware:

  • Raspberry Pi Zero W (or Pi 4 for newer builds)
  • MicroSD Card (8GB+ Class 10)
  • Waveshare 1.3" LCD HAT (or 2.13" for newer versions)
  • Pi Camera Module v2 (or compatible)
  • Case (3D printed or purchased)
  • Power supply (USB-C for Pi 4, micro-USB for Zero)

All components needed for DIY assembly

🌱 Seed Management

SeedSigner Options:

  • Generate New Seed: Create cryptographically secure seed phrase
  • Import Existing: Load seed from hardware wallet or other source
  • SeedQR Import: Scan QR code containing encrypted seed data
  • Dice Roll Generation: True randomness using physical dice
  • Multi-Signature: Support for 2-of-3 and other setups

Critical: Always backup your seed phrase on paper/metal. Device is stateless!

📱 SeedQR - Secure Seed Import

What is SeedQR?

  • Encrypted QR Code: Contains your seed phrase in encrypted format
  • Secure Transfer: Import seed without manual typing
  • Backup Solution: Store encrypted seed as QR code
  • Cross-Device: Works between different SeedSigner devices
  • Password-Based: SeedQR itself serves as the password

Advantage: Eliminates manual seed entry errors and speeds up setup process

💰 Transaction Workflow

  1. Watch-Only Wallet: Set up wallet with xpub (no private keys)
  2. Create Transaction: Build unsigned transaction on networked device
  3. Export PSBT: Export as Partially Signed Bitcoin Transaction
  4. Generate QR: Convert PSBT to QR code
  5. Scan with SeedSigner: Camera captures transaction details
  6. Review & Sign: Verify details and sign with private key
  7. Export Signed PSBT: Display signed transaction as QR
  8. Broadcast: Scan back to networked wallet and broadcast

PSBT Standard: Enables compatibility with most Bitcoin wallets

🔒 Security Best Practices

  • Verify Software: Check signatures on downloaded images
  • Dedicated Hardware: Use SeedSigner components only for this purpose
  • Physical Security: Store device securely when not in use
  • Backup Seed: Multiple physical backups in secure locations
  • Test Small: Always test with small amounts first
  • Stay Updated: Keep firmware updated for security patches

⚠️ Limitations & Considerations

SeedSigner Limitations:

  • Technical Knowledge: Requires understanding of Bitcoin concepts
  • No Backup Device: Need separate backup strategy
  • Learning Curve: Takes time to master the workflow
  • Physical Setup: Requires assembly and configuration

Trade-off: Maximum security and privacy come with increased complexity
