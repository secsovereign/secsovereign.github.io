The Problem with Exchanges

  • Custodial risk: They hold your keys
  • Hacks: One breach can hit millions
  • Regulatory risk: Assets can be frozen
  • Counterparty risk: Bankruptcy = lost funds

FTX, Mt. Gox, and many others took user funds with them

What is SeedSigner?

  • Air-gapped: Never connects to the internet; signs via QR
  • Stateless: No permanent key storage on the device
  • DIY hardware: Raspberry Pi parts, ~$50–125
  • Open source: Auditable software and hardware
  • Private: No serial numbers or manufacturer tracking
  • Multisig-ready: Works in 2-of-3 and similar setups

How It Works

  1. Load seed on SeedSigner (generate or import)
  2. Create PSBT in a watch-only wallet on a networked device
  3. Scan unsigned PSBT into SeedSigner via QR
  4. Review and sign offline with the private key
  5. Scan signed PSBT back and broadcast

What You Need

  • Raspberry Pi Zero W (or Pi 4)
  • MicroSD card (8GB+ Class 10)
  • Waveshare 1.3" LCD HAT (or 2.13")
  • Pi Camera Module v2
  • Case + power supply

Total: ~$50–125 from common electronics suppliers

Setup

  1. Download and verify the official SeedSigner OS image
  2. Flash the microSD card
  3. Assemble screen, camera, and Pi
  4. Boot and confirm the device works
  5. Generate or import a seed
  6. Practice with small amounts first

Seed Management

  • Generate: New seed, including dice-roll entropy
  • Import: Type in an existing seed phrase
  • SeedQR: Scan an encrypted seed QR (faster, fewer typos)
  • Multisig: Participate in 2-of-3 and other setups

Critical: The device is stateless. Back up the seed on paper or metal.

Security & Trade-offs

  • Verify signatures on downloaded images
  • Use dedicated hardware for SeedSigner only
  • Keep multiple physical seed backups
  • Requires Bitcoin literacy and a learning curve
  • You assemble and configure it yourself
  • No built-in backup device — plan recovery separately
