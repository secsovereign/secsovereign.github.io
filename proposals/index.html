  • Getting a Quantum Upgrade Adopted Is a Security Problem

    Bitcoin Security Consortium · October 1, 2026

    PDF Markdown

    A research proposal to the Bitcoin Security Consortium. Adoption failure of a quantum-resistant upgrade is a security failure. The report maps activation precedent, holder migration from chain data, process conditions, and design failure modes.

  • Permanent Data Channel Closure

    BIP · Pre-Proposal · August 12, 2026

    PDF Markdown

    Works with: Static Per-Output Miner Fee, Dynamic Escalation of the Per-Output Miner Fee

    Bitcoin Improvement Pre-Proposal: permanent consensus closure of data embedding channels (per-item caps, aggregate witness limits, output templates, Tapleaf and P2WSH script analysis) to complement the per-output fee BIPs.

  • Dynamic Escalation of the Per-Output Miner Fee

    BIP · Pre-Proposal · July 23, 2026

    PDF Markdown

    Depends on Static Per-Output Miner Fee

    Bitcoin Improvement Pre-Proposal: optional EMA and 25th-percentile fee escalation on top of the static per-output miner fee so the deterrent does not decay over decades.

  • Static Per-Output Miner Fee

    BIP · Pre-Proposal · July 23, 2026

    PDF Markdown

    Works with: Permanent Data Channel Closure

    Bitcoin Improvement Pre-Proposal: a consensus transaction-fee floor of a fixed satoshi amount per new non-coinbase output, pricing permanent UTXO-creation costs that relay policy cannot bind.
